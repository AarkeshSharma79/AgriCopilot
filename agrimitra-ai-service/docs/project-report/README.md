# Project Report

Place final submission documents in this folder, for example:

- `AgriMitra_Synopsis.docx` — the college synopsis report.
- `AgriMitra_SIH2026_Ideation.pptx` — the SIH ideation deck.
- Any final project report, viva documentation, or presentation materials.

This folder is intentionally kept empty of generated content in version
control (see `.gitignore`) — it is a working location for documents you
maintain locally and submit separately, not build artifacts produced by
either service.
